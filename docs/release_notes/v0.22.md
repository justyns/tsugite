# v0.22

## 0.22.0 (unreleased)

### Features

- A job on the `cc` executor is nudged to commit and summarize before its phase timeout ends the worker.
- Workspace `.html` files render in the file browser inside a sandboxed frame, with a source view alongside.
- Agents can open a workspace file or generated text in a pane beside the chat with `open_artifact`.
- Job records include `last_activity_at`, the time a job's executor started its worker or last saw output from it.
- Markdown and HTML the agent generates render in the app's theme in the artifact pane.
- Claude Code subscription limits appear on the Usage screen, the `/api/usage/providers` endpoint, and `tsu usage providers`.

### Fixes

- The command palette lists views only when a query matches one.
- Usage and history record a session's `/model` override as the turn's model.
- A turn killed by a provider error records `session_end` as errored, with the provider's message.
- A `run_if` guard that declines leaves nothing in history.
- A skipped run is recorded as skipped.
- Raw HTML in a workspace markdown file renders as text.
- A `javascript:` link in a workspace markdown file renders without its anchor.
- `session_reply` to a session that is already working queues the message for the start of that session's next turn.
- `session_reply` returns a `status` of `delivered` or `queued`, and `response` is `null` for a queued message.
- A negation in a nested `.gitignore` re-includes the file for `list_files`, the way git resolves it.
- A turn records the prose before the code block as its thought when the code itself contains a `Thought:` line.
- Console output keeps reaching the terminal after a multi-step run renders its metrics or plan table.
- A content block named after a tool leaves the tool callable on the subprocess executor.
- `spawn_agent`'s `timeout` ends a subagent that stops producing output without exiting.
- A browser tab reconnecting to a restarted daemon receives live events again.
- A scheduled run that reports an error leaves `max_runs` untouched.
- A job awaiting input appears in the agent's job context alongside the running ones.
