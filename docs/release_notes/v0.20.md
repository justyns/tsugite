# v0.20

## 0.20.0 (unreleased)

### Features

- Plugins can add pages to the web UI with `@ui_surface` or `register_ui_surface()`, each opening as a docked tab or a nav-rail view.
- A `@ui_surface` function returns the page's HTML, so a plugin can ship a page with no assets directory.
- A UI surface receives the daemon events it declares, forwarded into its frame over the plugin bridge.
- The `tsugite-onlyoffice` plugin edits `.docx` files from a configured directory in an embedded ONLYOFFICE Docs editor.
- `@onlyoffice` tools read a document's numbered paragraphs and comment threads, edit its text, and add, reply to and resolve comments, leaving the rest of the file as it was.
- A document open in the editor picks an agent's edit up in place.
- A `plugins` entry in `config.json` with a `path` loads that single Python file as a plugin, registering its `@tool`, `@hook`, `@subscribe`, and `@ui_surface` decorators.
- Double-clicking a chat in the sidebar opens it as a new tab in the focused pane.
- `with tsu_group("..."):` in agent code labels the calls it wraps, and the chat renders each group as a named section of the code block.
- A finished code execution folds to one line in the chat, listing its `tsu_group` titles; a failed one stays open.
- A session metadata value that is an `http(s)` URL shows as a link chip in the chat header, labelled by its key or by a `label` set alongside the `url`.
- `View metadata` in the session menu shows a session's raw metadata JSON and its links.
- The `restart_daemon` tool restarts the daemon once the user approves.
- A compaction summary is a handoff briefing for whoever picks the conversation up next.
- Compaction summaries carry a Goal section, the reason behind each decision, and the URLs and identifiers the work referred to.
- A new setting renders soft line breaks as hard line breaks in your own messages.
- The top bar lists your spaces, each holding its own pane layout: split a chat beside a note in one space, keep a fullscreen chat in another, and switch between them.
- Spaces can be created, renamed and closed from the top bar.
- Closing a space offers an undo that restores it and its layout.
- Spaces reorder by dragging them along the top bar.
- Pinned chats reorder by dragging them in the sidebar.
- Tabs reorder by dragging them along their pane's tab strip.
- Dragging a tab onto the middle of another pane moves it there.
- `tsu --version` and `tsu -V` print the version.

### Fixes

- Multi-step agents run in daemon sessions, background jobs, Discord, and the REPL.
- A note in a split pane fills the pane once its metadata column collapses.
- The spaces strip keeps its width at phone sizes.
- A reply built from tool-call markup gets the turn back with a correction pointing at the `python-exec` fence, and a run that answers with it twice is recorded as failed.
- A job retry whose executor fails to start carries that failure instead of showing as running.
- Events emitted by a tool running under the subprocess executor, including file reads and writes, reach the event bus.
- An open file tab picks up an agent's `write_file` or `edit_file` edit, and warns instead of overwriting when the editor holds unsaved changes.
- An agent's `custom_tools` entry runs that agent's own command when another agent defines a tool of the same name.
- A skill loaded during one run is visible only to that run, including when two chats run at once.
- `claude_code` agents run without the CLI's user and project `CLAUDE.md` files.
- A schedule whose run ended in an error, was interrupted, or was cancelled is listed as an error with that run's message.
- Turning off the Auto-follow setting stops a conversation scrolling to new output as it streams.
- A second Enter or click straight after sending leaves the new turn running.
- `codex_cli` gpt-5.5 and gpt-5.4 report the 272k context window the subscription backend serves.
- A response that writes runtime-only tags is logged and raised as a warning when those tags are neutralized.
- Agent frontmatter fields survive inheritance resolution: `run_if`, `strict_tools`, `skill_paths`, `model_kwargs`, `disable_history`, `auto_context`, `visibility`, `spawnable`, `network`, `sandbox`, and `allowed_secrets`.

### Changes

- Unloading a skill from the web UI takes effect on the session's next turn.
- `plugins.<name>.enabled` in `config.json` gates tool, hook, event-subscriber, and attachment plugins.
- Removed the `tsugite.tools`, `tsugite.hooks`, and `tsugite.event_subscribers` entry-point groups.
