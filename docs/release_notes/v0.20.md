# v0.20

## 0.20.0 (unreleased)

### Features

- Adapter plugins can add pages to the web UI with `get_ui_surfaces()`, each opening as a docked tab or a nav-rail view.
- A UI surface receives the daemon events it declares, forwarded into its frame over the plugin bridge.
- The `tsugite-onlyoffice` plugin edits `.docx` files from a configured directory in an embedded ONLYOFFICE Docs editor.
- `@onlyoffice` tools read a document's numbered paragraphs and comment threads, edit its text, and add, reply to and resolve comments, leaving the rest of the file as it was.
- A document open in the editor picks an agent's edit up in place.
- A `plugins` entry in `config.json` with a `path` loads that single Python file as a plugin, registering its `@tool`, `@hook`, and `@subscribe` decorators.
- Double-clicking a chat in the sidebar opens it as a new tab in the focused pane.
- `with tsu_group("..."):` in agent code labels the calls it wraps, and the chat renders each group as a named section of the code block.
- A finished code execution folds to one line in the chat, listing its `tsu_group` titles; a failed one stays open.

### Fixes

- Multi-step agents run in daemon sessions, background jobs, Discord, and the REPL.

### Changes

- `plugins.<name>.enabled` in `config.json` gates tool, hook, event-subscriber, and attachment plugins.
