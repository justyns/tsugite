# v0.19

## 0.19.0 (unreleased)

### Features

- Rebuilt web UI in Svelte 5 ("Operational Console"): ⌘K command palette, dockable split-pane workspaces, five themes, and new Secrets, Plugins, Tools, and workspace-files views.
- Image and photo uploads reach vision-capable models, with a mobile camera button, inline thumbnails, and a lightbox.
- "Add context" menu attaches structured context as chips: browser location, `@` workspace files, and plugin-provided sources.
- Web-fetched context is marked untrusted and gated on per-host approval.
- Attach a session, job, or terminal to a chat.
- Live token-by-token streaming of chat turns, including `python-exec` code and per-tool-call rows.
- Reasoning/thinking is persisted to history.
- Claude Opus 5 in the model registry (`claude_code:opus-5`).
- Slash commands in the ⌘K palette, contributable by plugins, with typed argument autocomplete.
- `/model` and `/effort` set per-session overrides (web and Discord).
- More keyboard shortcuts with a `?` overlay, and "New chat" from any view.
- Raw-messages inspector for any past session.
- VSCode-style file preview tabs.
- Load agents from multiple directories (`agent_paths`); group agent `attachments:` into prompt-cache tiers.
- `spawn_agent`/`spawn_job` accept `files=[...]`.
- Usage tab breaks out scheduled tasks and adds cache columns plus a per-reply cache footer.
- Session-source tags (web/discord/cli) and new endpoints (`POST /api/jobs`, `GET /api/plugins`, `GET /api/tools`).

### Fixes

- Removed the reactions feature.
- Background spawns, jobs, and chat routing resolve the correct daemon agent again.
- Claude Code chats self-heal when a resumed transcript becomes unresumable.
- Approval prompts are durable and survive reloads.
- Conversations open fast and stay live across tabs, schedules, and Discord.
- Per-turn token usage persists again, and `anthropic:` no longer crashes after the first turn.
- Ended chats collapse into their own searchable, restartable section.
- Model picker is grouped by provider with context, price, and capability details.
- Streaming no longer fights your scrolling.
- Many mobile fixes: escapable full-screen views, drill-down navigation, reachable Settings and effort controls, Enter inserts a newline, and drafts/photos persist across reloads.
