# v0.21

## 0.21.0 (unreleased)

### Features

- An Activity view lists finished session runs, resolved jobs, schedule runs and compactions, filtered by type.
- Schedules can now deliver their result into a session
- Sessions can be marked as needing the user's attention until it is ack'd
- Warn when scheduled sessions fail too many times
- Session tools and `schedule_create` use current chat session by default

### Breaking changes

- The daemon `agents:` config block is gone. `daemon.yaml` now takes flat defaults (`default_workspace_dir`, `default_agent_file`, `default_model`, `default_compaction_model`, `default_context_limit`, `default_max_turns`, `timezone`, `auto_compact`), and sessions override them individually. Convert an existing config with `python scripts/migrate_daemon_agents.py <path-to-daemon.yaml>`; the daemon refuses to start while an `agents:` block is present.
- Discord bots no longer take an `agent:` binding.
- Webhooks no longer take an `agent`; `POST /api/webhooks` requires only `source`.
- `/api/agents/{agent}/...` routes are now `/api/chat/...`, `/api/workspace/...`, `/api/hooks` and `/api/commands/{name}`. `GET /api/agents` is now `GET /api/runtime`, and the admin model PATCH is `PATCH /api/runtime/config`.
- `GET`/`PATCH /api/sessions/{id}/settings` drops `agent` and accepts `context_limit`. Both now require authentication.
- Adapter plugin factories take `runtime=` in place of `agents_config=`.
- `tsu run --daemon` takes no agent name and joins the daemon's most recent session.
- `tsu daemon sessions` and `tsu daemon compact` take no agent argument; `tsu daemon schedule add --agent` and `tsu daemon session clear-primary --agent` are gone.
- The `schedule_create`, `background_task`, `start_session` and `list_sessions` tools drop their `agent` parameter.
- A session's primary flag is scoped per user rather than per user and agent.
- Schedule API tokens identify as `schedule:<schedule_id>`.

### Changes

- Relative timestamps older than a month render as local dates, with the year once older than a year.
